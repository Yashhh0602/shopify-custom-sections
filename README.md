# Shopify Custom Section — Featured Quick View

A production-ready custom Shopify Liquid section built from scratch.

## Features
- Responsive 4-column product grid
- Dynamic New/Sale badge system
- Smooth hover animations
- Quick View modal with product image, title, price and description
- Separate CSS asset file following Shopify theme best practices

## Tech Stack
- Shopify Liquid
- CSS Grid
- Vanilla JavaScript
- Shopify Theme Architecture

## Files
- `featured-quick-view.liquid` — Main section file
- `fqv-styles.css` — Stylesheet
